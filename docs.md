# CLI

Keep a record of the time you dedicate to your projects.

**Usage**:

```console
$ [OPTIONS] COMMAND [ARGS]...
```

**Options**:

* `-v, --version`: Show the application&#x27;s version.
* `-w, --website`: Launch the usetrak.com website.
* `-r, --repository`: Launch the trak repository.
* `-i, --issues`: Launch the trak issues page on Github.
* `-b, --bug`: Report a bug on Github.
* `-d, --docs`: Launch the documentation website.
* `--install-completion`: Install completion for the current shell.
* `--show-completion`: Show completion for the current shell, to copy it or customize the installation.
* `--help`: Show this message and exit.
